# MannMitra

Product authority: `mannmitra-master-spec.md.md`. Delivery plan: `plans/mannmitra-blueprint-opencode.md`. Current progress: `HANDOFF.md`.

MannMitra is a non-clinical mental wellbeing screening and thirty-day self-help web app for young-adult Indian users. It combines the MHI-18 pretest, a server-side risk gate, program tracks, daily mood check-ins, a mood garden, and a final reflection report. Screening is not diagnosis. Users who need professional support must not be offered self-help as a substitute for it.

The product uses calm, non-alarming language. It has no shaming streak messages. Authentication supports email/password, six-digit email codes and Google sign-in, with server-side account rules. Privacy, accessibility and reduced-motion support are required.

The current request is to implement the supplied Fluid Glass HTML as the public landing page in blueprint Step 8. The user has already selected that visual direction. This document records the existing specification and request; it adds no product decisions.
